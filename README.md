# EEGBind for NeuroMM 2026 Source Localization

Inference code for our selected five-fold solution to **NeuroMM 2026 Track 3: NMM-Source-IED**. It predicts one of five IED source classes from EEG and the seven official video feature routes. The selected submission achieved **0.8395 weighted F1** on the public leaderboard.

The release contains the selected EEG backbone, attentive EEG–video classifier, candidate feature loader, five-fold log-probability ensemble, and a subject-disjoint fold generator. It is an inference reproduction package: the earlier initialization checkpoint and full training chain are not bundled. The six released checkpoints are sufficient to reproduce the selected inference pipeline.

The complete codebase underlying this work will be made publicly available in November 2026.

## Data and weights

Obtain the [official NeuroMM data](https://2026.neuromm.org/challenge.html). The candidate directory must contain `candidate_ids.txt`, `eeg/<sample_id>.npy`, and seven video feature folders under `video/`.

Download the [Track 3 checkpoints on Hugging Face](https://huggingface.co/neuro1104/NeuroMM2026-IED-Detection). The model repository contains only five fold checkpoints, one EEG backbone checkpoint, and their checksum manifest. Download, link, and verify the weights:

```bash
hf download neuro1104/NeuroMM2026-IED-Detection --local-dir /path/to/track3-weights
python scripts/prepare_weights.py --source /path/to/track3-weights --verify
```

The script checks each SHA-256 and makes local links named `fold_0.pt` through `fold_4.pt` and `eeg_anchor.pt`. Checkpoints and challenge data are excluded from Git.

## Run inference

```bash
conda env create -f environment.yml
conda activate neuromm-source-ied
pip install -c constraints.txt -r requirements.txt
pip install -e .

export NEUROMM_DATA_ROOT=/path/to/extracted/neuromm26_data
export NEUROMM_OUTPUT_ROOT=/path/to/output
bash scripts/run_inference.sh
```

The final file is `$NEUROMM_OUTPUT_ROOT/submissions/submission.zip`. It contains one `submission.csv` with columns `sample_id,prediction` and class values 1–5. Use `DEVICE=cpu` to run without CUDA; it will be slow. Five fold diagnostics are also written for the log-probability ensemble.

## Fold generation

[scripts/make_subject_folds.py](scripts/make_subject_folds.py) creates subject-disjoint training manifests from the official labeled training manifest. It does not read candidate examples.

```bash
python scripts/make_subject_folds.py \
  --input-manifest /path/to/official/labeled_training_manifest.csv \
  --output-dir outputs/source_localization_folds
```

## Candidate labels and leakage

Candidate inference reads all sample IDs in the official order and uses only their EEG and video features. The temporary candidate manifest leaves labels blank; the EEG loader uses a sentinel value that is never passed to the classifier. The code does not select a private scored subset or modify individual predictions from candidate IDs, inferred labels, or leaderboard feedback. Every candidate receives a prediction.

The ensemble averages five model log-probability vectors with equal weights. Its only inputs are the fold diagnostics generated by the inference script.
